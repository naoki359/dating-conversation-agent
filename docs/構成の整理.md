# 構成の整理

## base nodeの役割

- ログを共通で出力する（ファイルで詳細に）
- コンソール（ゆくゆくはUI）上に思考過程を出力


## データ領域

### SourceData

初期登録後は読み取り専用

- user_id
- プロフィール
- 過去の会話
- 自身のプロフィール

### ReactState

Lang Graphでバケツリレーを行うパラメータ

ReActで必要になる情報を入れる

- 現在の考え
- 実行するツール名

### Canvas

1ループで作られる最終的なアウトプット

- 返信内容
- 成果物の説明

## 必要なノード

- deside
- action

## 必要なツール

- 返信生成
- SourceData取得

## 検討事項

- base nodeの取り扱い
  - base nodeを利用することで、ノードごとのルールを統一したいが、実装が複雑になる
  - そのうえログの出力しか実施していないので少し手間となっている
