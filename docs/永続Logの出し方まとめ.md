# 永続ログの出し方まとめ

## 目的（Why）

1. 非決定的な挙動を後から検証するため

```
エージェントは同じ入力でも振る舞いが揺れるため、実行時の記録がないと原因分析や再評価ができない。
```

2. コード変更なしの劣化（回帰）を検知するため

```
プロンプト・知識・モデル・ツールの変化で挙動が変わるので、継続的なログ比較が必要。
```

3. 説明責任を果たすため

```
問題発生時に「何をしたか」だけでなく「なぜそう判断したか」まで追跡できる状態が求められる。
```

4. 継続的チューニングの材料にするため

```
本番での行動データを蓄積して評価・改善ループを回し、運用しながら価値を高めるため。
```

## 設計（How）

base node にログを出力する処理を実装する

すべてのnodeはbase node を継承する規定とする
